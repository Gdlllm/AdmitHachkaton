# Промежуточный снимок MOTION

Это промежуточный архив по запросу пользователя. Работа над проектом продолжается.

Включены исходники, локальные ML-модели и WASM, зависимости, собранная версия dist, пять тестовых видео, тесты и текущие результаты. В tests/artifacts есть локальные тестовые изображения — учитывайте это перед публикацией архива.

Запуск на этом Mac: npm run dev -- --port 5173
На другой машине: npm ci && npm run setup, затем npm run dev.

Проверено: непрерывный прогон пяти роликов (880 уникальных кадров), 17 браузерных сценариев. При дополнительном тесте увеличенной ладони найден один ложный Face; исправление ещё обсуждается.

Количество точек моделей: тело 33, лицо с радужками 478, две кисти по 21. Отрисовка некоторых деталей меняется в зависимости от размера области в кадре.
